Inspected Pi `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: it directly imports `@earendil-works/pi-tui`, constructs TUI/editor/container resources, and imports mode-specific terminal components. That placement is Pi-like but not frontend-neutral.

Split OpenZi accordingly. `packages/coding-agent/src/modes/interactive/interactive-mode.ts` now contains only client-independent session/generation, prompt, queue, abort, and replacement operations with no OpenTUI/TUI imports. It uses a narrow synchronous `subscribe()` and has no Nano Stores dependency. `packages/tui/src/interactive/` owns Nano Stores, `InteractiveTui`, renderer lifecycle, presentation state, imperative components, and UI behavior tests.

Dependencies are `cli -> coding-agent`, `cli -> tui -> coding-agent`; the CLI dynamically composes the core mode and TUI client and disposes the mode/session it creates.

Removed every standalone external visual-reference mention from documentation, reference pins, source comments, exported symbols, and test names. Renamed the built-in palette to `defaultTheme`.

Rewrote ADR 0007 and amended architecture, terminal client architecture, ADRs 0003/0005/0006, terminology, engineering rules, README, and roadmap evidence. Full workspace check passes.
