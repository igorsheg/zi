Completed the interactive keybinding nuclear refactor.

Owner and API:

- Added one immutable, instance-scoped `InteractiveKeybindings` constructed by `InteractiveMode`.
- Added closed semantic IDs for application interruption/clear/exit, queue actions, generic input/select actions, and transcript navigation.
- Added normalized per-mode overrides, explicit disablement, bounded keys per action, unknown-action/modifier validation, duplicate removal, effective binding metadata, display hints, user-conflict reporting, and Pi-derived reserved/overridable extension policy.
- `runTui` and `InteractiveMode` accept typed per-mode overrides; the TUI package exports the keybinding surface.

Dispatch boundaries:

- `InteractiveKeybindings` translates OpenTUI key events plus concrete prompt context into closed prompt/transcript actions. It contains no callbacks and executes no business operations.
- `PromptView` and `TranscriptView` no longer contain physical product chord checks. They apply closed actions to their owned OpenTUI resources and stores.
- Native selection copy precedes picker cancellation; picker actions precede prompt actions; empty-editor and streaming facts are admitted by the key owner; unsupported picker submit/navigation variants remain consumed.
- OpenTUI retains ordinary editing, cursor, focus, selection, and scroll mechanics.
- Double-clear temporal state remains in `InteractiveMode`; cancellation and queue workflows remain in stores/`AgentSession`.
- Queue and unseen-output hints derive from effective bindings.

Future extensions:

- Effective bindings expose descriptions, canonical keys, and reserved-versus-overridable policy so the future coding-agent extension owner and terminal aggregate can resolve contributions without mutable global registration or component callbacks.

Evidence and docs:

- Added pure tests for defaults, contextual actions, remapping, disablement, normalization, validation, bounds, hints, metadata, and conflicts.
- Added real OpenTUI remapping coverage across prompt clear/exit/newline, picker navigation, transcript navigation, and visible hints while retaining all lifecycle/selection tests.
- Added ADR 0010 and updated AGENTS, terminology, architecture, TUI architecture, README, ADRs 0005/0009, and the parity roadmap with Pi `0e6909f0` provenance.

`bun run check` passes with 33 coding-agent tests and 79 TUI tests.
