Added Pi-inspired live Write line counts at the semantic projection boundary.

- Preparing Write rows update a bounded `lines so far` fact from the current streamed argument snapshot.
- Once arguments settle, line and byte counts are exact; completed typed details remain authoritative.
- Counts describe model argument generation, never incremental filesystem progress.
- Large partial arguments stop at the existing 50 KiB presentation bound and report `at least N lines so far`, avoiding an 8 MiB rescan per token.
- One ToolCallView root survives every count update and completion.
- Added projection, lifecycle, bound, and documentation coverage.
- Verified in the full `bun run check`; rebuilt `dist/zi`.
