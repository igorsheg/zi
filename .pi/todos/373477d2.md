Implemented owner-driven opt-in memory snapshots. AgentSession lazily accounts committed JSON bytes and then advances incrementally, and reports streaming/queue/subscriber retention. InteractiveMode composes process memory, session data, renderable and renderer-buffer counts, lifecycle/live requests, and renderer/key-input listeners. ZI_TUI_MEMORY=1 adds three memory rows to the existing frame-driven overlay, sampled at most every three seconds with no timer or retained history. Updated the performance spec and deterministic tests. Full `bun run check` passes.
