Implemented a per-AgentSession Authentication owner over the runtime's shared Models/FileCredentialStore. Provider-derived OAuth/API-key catalogs, generic bounded prompt/event forwarding, locked credential commit, redacted listing, stored-only logout, explicit idle/logging_in/logging_out/disposed lifecycle, operation identity, AbortController cancellation, disposal settlement, stale-result rejection, and overlap guards are covered. AgentSession gates auth against runs/model changes, joins interruption and shutdown settlement, emits credential-free authentication_changed events, and selects/persists the provider's first model for unselected sessions. Tests cover multi-field API key, browser/device OAuth, select/manual code, Pi AI-owned refresh, bounds, ambient auth after logout, cancel/dispose races, and session integration.
