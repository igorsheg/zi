Implemented the P0.5 interruption and terminal-shutdown contract.

Coding-agent ownership:

- Added `AgentSession.abortAndDiscardQueuedInputs()` for shutdown. It detaches admitted queues before entering `aborting`, signals the agent, and returns shared run settlement without allowing queued continuation.
- Kept Escape on `takeQueuedInputsAndAbort()` so pending steering/follow-up input is returned to the composer.
- Kept lower-level `abort()` queue-preserving; it is explicitly not terminal shutdown.
- Queue publication now uses `try/finally` so an observer failure cannot prevent the active agent from receiving abort.
- Added provider/queue behavior coverage and direct bash process-group cancellation coverage, including a SIGTERM-resistant descendant.

Terminal input ownership:

- `InteractiveMode` owns `ready | armed { pressedAt }` for Pi's 500 ms double-Ctrl+C gesture.
- Native selection copy and picker back consume Ctrl+C first and reset any prior arm.
- First unconsumed Ctrl+C clears the composer without interrupting active work; the second requests exit.
- Ctrl+D remains empty-composer exit. Escape remains cancellation with queue restoration.
- Async provider failures surface in focused prompt feedback.

Terminal-run ownership:

- `runTui` owns `running | closing | closed` and admits only one close transition across interactive exit, SIGHUP/SIGINT/SIGTERM, and renderer destruction.
- Close stops mode input, starts cancel-and-discard, clears the title, and destroys OpenTUI immediately.
- Session settlement is then awaited outside the alternate screen with the existing five-second deadline.
- Concurrent close requests share completion; signal handlers are removed; shutdown failures propagate only after terminal restoration.
- TUI does not dispose the caller-owned session; CLI retains final disposal and post-terminal error reporting.

Documentation:

- Added ADR 0009 with Pi `0e6909f0` and OpenCode `cb8be9ba1` provenance.
- Updated AGENTS, terminology, architecture, TUI architecture, README, ADR 0005, and the parity roadmap.

Validation:

- `bun run check` passes with 33 coding-agent tests and 71 TUI tests.
