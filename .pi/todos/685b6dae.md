- Added closed typed failures for invalid paths, non-file targets, permission denial, oversized writes, and other unwritable destinations.
- Preserved cancellation as a thrown owner transition without fabricating an operational error body.

- Empty writes remain a one-row success; argument previews are bounded before normalization and truncation guidance is detailed-only.
- Failures replace attempted content with one bounded semantic error body, avoiding content leakage and duplicate notices.
- Constrained headers retain whole detail facts in order and preserve lifecycle status instead of clipping partial facts.
- Covered execution, overwrite/empty/single-byte behavior, restoration, malformed input degradation, bounds, cancellation, stable lifecycle identity, compact/detailed density, narrow widths, failure privacy, and visual parity.
