Implement the agreed Pi-grounded session slice: bounded current-cwd listing and continue-recent resolution, narrow AgentSessionRuntime replacement owner, TUI /new and /resume through PromptStore/PickerStack, CLI continue/resume compatibility, torn-tail session loading hardening, ADR/documentation, and behavior tests. Keep Pi as parity reference and Grok Build as scale/failure-case reference; do not import ACP/actor/remote architecture.

## Implemented

- Added bounded `SessionManager.list()` metadata previews, current-cwd filtering, recent continuation, file-size validation, invalid/omitted reporting, and malformed unterminated-tail recovery.
- Added explicit `AgentSessionRuntime` replacement/cancellation/disposal owner. New-session candidates are removed on pre-commit cancellation; cross-cwd switch reconstructs the complete runtime; failed construction and pre-commit races preserve the old session.
- Added `/new` and `/resume` to coding-agent command descriptors and the composer-owned TUI workflow, with after-open async listing, stale-session checks, replacement cancellation, full screen/session rebinding, and focus preservation.
- Added strict CLI `--resume`/`-r` and `--continue`/`-c`. Interactive CLI construction now uses the replaceable runtime while headless modes retain one caller-owned `AgentRuntime`; the follow-up removed the temporary `--session` alias.
- Added ADR 0012, architecture/glossary/README/roadmap updates, and pinned Grok Build as a secondary scale/failure reference.
- Acceptance coverage added in session-manager, agent-session-runtime, TUI session-selector, CLI args/run, runtime path, command catalog, and SDK consumer tests.

Verification: `bun run check` passes (133 coding-agent tests, 109 TUI tests, 20 CLI tests, 7 script tests).
