Turn the CLI into process-only mode composition after coding-agent text/JSON behavior exists.

Dependencies:

- Depends on `TODO-e1696402` and `TODO-3d1e23c6`.

CLI responsibilities:

- Extend argument parsing for Pi-compatible `--print`/`-p`, `--mode text`, and `--mode json`, plus ordered positional prompt messages. Keep RPC explicitly unsupported/deferred.
- Resolve application mode from explicit flags and TTY facts: JSON wins when requested; print is selected by `-p` or non-TTY stdin/stdout; otherwise use interactive mode.
- Read bounded piped stdin only outside future RPC mode and combine it with positional prompt input using a documented deterministic rule.
- Reject headless execution with no prompt, no selected model, invalid mode combinations, or incompatible session flags using stderr and nonzero exit status.
- Keep CLI ownership of process signals, stdin/stdout/stderr, exit code, mode selection, and final session disposal.
- Preserve terminal isolation: dynamically import `@zi/tui` only for interactive mode. Text/JSON/help failures must never initialize OpenTUI, raw mode, terminal title, browser opener, or TUI Nano Stores.
- Adapt process stdout/stderr to the bounded writer/result contracts from coding-agent. Flush before process completion and respect backpressure.
- Restore/abort in the correct order on SIGTERM/SIGHUP; do not use `process.exit()` before bounded cleanup except where the existing process contract requires it.
- Keep startup/settings diagnostics on stderr in headless modes; JSON stdout must remain strict JSONL only.
- Update help and README examples without exposing API keys.

Acceptance tests (prefer spawned CLI processes for process boundaries):

- `zi -p "prompt"` and `zi --mode text "prompt"` print final text and return 0.
- `zi --mode json "prompt"` emits parseable JSONL and no ANSI/chatter.
- Piped stdin selects text print mode and is bounded.
- Explicit interactive mode still loads the TUI; print/JSON modes provably do not import or initialize it.
- Provider errors and missing model return nonzero with clean stdout/stderr separation.
- SIGTERM/SIGHUP abort active provider/tool work, flush output, remove listeners, and let the CLI dispose the session exactly once.
- `--no-session`, explicit session files, `--model`, and memory-only `--api-key` retain their existing semantics in headless modes.
- Help lists supported modes and states that RPC is not yet available, rather than silently accepting it.
