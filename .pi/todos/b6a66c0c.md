Verified pi-mono's split at pinned commit 0e6909f0 and corrected OpenZi accordingly.

Pi ownership:

- `core/slash-commands.ts` owns immutable built-in descriptors.
- `ExtensionRunner` owns extension registrations; prompt templates and skills remain session/resource-owned.
- terminal `InteractiveMode` aggregates descriptors for autocomplete and parses/dispatches built-in invocations.
- `pi-tui` Editor owns only autocomplete/input mechanics.

OpenZi correction:

- added `packages/coding-agent/src/slash-commands.ts` for descriptors of supported built-ins.
- added mode-owned `packages/tui/src/interactive/interactive-commands.ts` for completion aggregation and parsing into a closed `InteractiveCommand` union.
- `InteractiveMode` constructs and owns `InteractiveCommands` and injects it into the active screen.
- `PromptStore` receives typed command intents and owns only active completion plus prompt/model-selector workflow.
- removed `/model` names, argument hints, descriptions, and parsing from `PromptView` and `PromptStore`; the view now renders descriptors generically.
- extension/template/skill catalogs remain deferred to their concrete coding-agent owners rather than a speculative global registry.

Added coding-agent registry coverage and retained all `/model` integration coverage. Updated ADRs and architecture docs. `bun run check` passes with 30 coding-agent tests and 60 TUI tests.
