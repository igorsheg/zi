Removed React, @opentui/react, @nanostores/react, JSX, and React types from the workspace. Reversed ownership to `cli -> coding-agent -> tui -> @opentui/core`.

Moved interactive product ownership, stores, rendering, lifecycle, and all product behavior tests to `packages/coding-agent/src/modes/interactive/`. Added the isolated `@zi/coding-agent/modes/interactive` subpath and dynamic CLI import; the main coding-agent index does not eagerly load OpenTUI.

Reduced `packages/tui` to domain-free imperative Composer, PickerList, theme, and glyph APIs. Imperative owners subscribe directly to Nano Stores, mutate owned renderables, preserve durable transcript identities and native selection/scroll anchors, and dispose subscriptions/handlers explicitly.

Added ADR 0007, amended ADRs 0002–0006 where relevant, and rewrote architecture, terminal architecture, terminology, roadmap evidence, README, and engineering rules. Full workspace check passes: 79 coding-agent tests and 2 TUI tests.
