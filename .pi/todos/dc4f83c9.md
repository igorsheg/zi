Implemented the owner-first `/model` vertical slice against pi-mono commit 0e6909f0.

Ownership:

- `AgentSession` remains authoritative for configured catalog resolution, selection admission, model mutation, persistence, and events.
- `PromptStore` owns the closed composer/loading-models/model-selector/selecting-model workflow, slash completion, operation identity, status/error feedback, and stale completion rejection.
- `ModelSelectorView` owns its OpenTUI subtree and native search textarea. Live composer/search text is passed into store operations and never mirrored.
- `Composer` and `PickerList` remain domain-free; `PickerList` now centers selection like Pi.
- `InteractiveMode` routes focus to the active prompt surface and session replacement destroys the old workflow.

Behavior:

- `/m` slash completion, Tab completion, and Enter admission.
- `/model` opens only configured models.
- `/model <term>` directly selects a unique exact bare or provider/model reference; otherwise opens a prefiltered selector.
- Current model first, remaining models by provider; Pi fuzzy ranking; up/down wrap; Enter selects; Escape/Ctrl+C cancel; at most ten model rows.
- Success closes with `Model: <id>`; failure closes with an error; catalog failure stays in the selector.
- Cancellation, disposal, supersession, and session replacement reject stale loading/selection completions.

Evidence:

- `packages/tui/test/interactive/model-selector.test.ts`
- `packages/tui/test/picker-list.test.ts`
- existing `packages/coding-agent/test/model-selection.test.ts`

Updated architecture, TUI architecture, ADRs 0005/0006, and the parity roadmap. `bun run check` passes: 29 coding-agent tests and 60 TUI tests.
