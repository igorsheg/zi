Added Nano Stores 1.4.0 and @nanostores/react 1.1.0. Rebuilt TUI mutable state around factory-created, instance-scoped `InteractiveModeStore`, `PromptStore`, and `TranscriptStore`; no mutable module-global stores and no AgentSession/native-state mirroring.

Stores expose read-only atoms, computed narrow subscriptions, domain operations, explicit binding/disposal, pure transitions, stale-event rejection, bounds, and prompt settlement cleanup. React now subscribes and binds OpenTUI resources; native textarea and scroll state remain in renderables/refs. Theme context remains immutable visual infrastructure.

Added store tests, ADR 0006, and rewrote TUI architecture, terminology, roadmap references, and engineering rules. Full workspace checks pass; TUI has 52 passing tests and coding-agent has 29.
