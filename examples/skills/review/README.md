# Review skill

Copy this directory to either:

```text
$HOME/.zi/agent/skills/review/
$HOME/.agents/skills/review/
<cwd>/.zi/skills/review/
<cwd-or-ancestor>/.agents/skills/review/
```

Trust project configuration when using the project location, then start a new session or run `/reload`. Zi may load the skill when asked to review changes; `/skill:review <request>` invokes it explicitly.
