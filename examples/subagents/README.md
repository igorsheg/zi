# Pathfinder subagent profile

Copy `pathfinder.md` to either:

```text
$HOME/.zi/agent/subagents/pathfinder.md
<cwd>/.zi/subagents/pathfinder.md
```

Trust project configuration when using the project location, then start a new session or run `/reload`. Ask Zi to delegate a bounded repository search to the `pathfinder` profile. Omitted model selection inherits the parent session's current model.

See [`docs/subagents.md`](../../docs/subagents.md) for the profile contract, standard orchestration tools, limits, and lifecycle.
